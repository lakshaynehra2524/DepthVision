User Guide & Model Information

Purpose

DepthVision estimates object depth and spatial distances using a single RGB image.


Supported Formats

  • JPG
  • JPEG
  • PNG

Workflow

  1. Upload image
  2. Depth estimation model predicts depth map
  3. YOLOv8 detects objects
  4. 3D coordinates generated
  5. Distances calculated
  6. Risk analysis performed
  7. Annotated image generated

Output

  • Annotated Image
  • Detected Objects Table
  • High Risk Pair Analysis
