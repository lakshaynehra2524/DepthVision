About DepthVision

AI-Based Object Distance & Risk Detection System

Project Overview

DepthVision is an AI-powered computer vision system that combines monocular depth estimation with object detection to estimate spatial relationships between objects present in an image.

Core Features

  • Monocular Depth Estimation
  • YOLOv8 Object Detection
  • 3D Coordinate Generation
  • Object Distance Analysis
  • Risk Detection Engine
  • Visual Risk Highlighting

Technology Stack

  • Python
  • FastAPI
  • PyTorch
  • YOLOv8
  • OpenCV
  • HTML / CSS / JavaScript
